# Ekran görüntüleri

Teslim için buraya en az iki görüntü koyun:

| Dosya | Ne göstermeli |
| --- | --- |
| `01-normal.png` | Dört kartın normal görünümü (sağlıklı + bozuk hedef) |
| `02-alarm.png` | Challenge 6 kapalıyken Mini Envanter kartında **⚠ ALARM** |

## Nasıl alınır?

1. `python -m streamlit run dashboard.py`
2. Tarayıcıda ekran görüntüsü alın (Win + Shift + S veya tarayıcı araçları).
3. Dosyaları bu klasöre kaydedin.
4. Alarm görüntüsü için Challenge 6 API'yi durdurup 3 kez **Şimdi Yenile** basın.
